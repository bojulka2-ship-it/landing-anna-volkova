# Шаблон промпта для лендингов

Готовый промпт полного цикла: от вопросов заказчику до демо на GitHub Pages, тестов и документации. Основан на процессе проекта «ТверьКамень» (Z3).

## Использование

1. Открыть нового ИИ-агента.
2. Скопировать блок «ПРОМПТ → КОНЕЦ ПРОМПТА» из [PROMPT.md](PROMPT.md).
3. Заполнить `[[ ]]` данными проекта.
4. Ответить на вопросы фазы 0 — дальше агент работает по фазам сам.

Команды по ходу: «Начинаем» · «залей демо» · «приёмка».
